# AI Red Teaming & Guardrail Pipeline
**Portfolio Project: LLM Vulnerability Auditing and Defense**
This repository demonstrates a local cybersecurity lab running on Fedora Linux. It showcases automated prompt injection vulnerability scanning against a local Llama 3.2:1b instance using NVIDIA Garak. To mitigate exploits, a dual-model defensive architecture was engineered using LangChain and Meta's Llama Guard 3, effectively intercepting adversarial payloads.
